# Analizador léxico de GO

Construir un analizador léxico que devuelva los componentes léxicos que aparecen en el programa `concurrentSum.go`, codificado en el lenguaje Go.

## Estructura del proyecto

- proyecto/ (carpeta raíz)
    - bin/ (ejecutable final)
    - doc/ (documentación)
    - src/ (código fuente, cada .c)
    - inc/ (cabeceras, cada .h)
    - lib/ (dependencias)
    - obj/ (archivos .o)
    - LICENSE (licencia de uso)
    - Makefile
    - README.md
    - TODO.md
    - enunciado.md
    - currentSum.go
